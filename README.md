# Allegro P/SDLC Framework — landing page

An educational landing page for the Allegro P/SDLC Framework, adapted from the [existing Flower Framework prototype](https://misskapcia.github.io/flower-framework-ak/index.html#flower). The original page remains a separate site.

Open `index.html` in a browser. The static page loads `app.js`, `styles.css`, `dune-theme.css` and `dune-redesign.css`; no build step is required. GitHub Pages can serve this repository from the root of `main`.

The page keeps the seven interactive petals, Discovery grouping, shared evidence core, artefacts, Observable Flow metrics and framework principles. An illustrative example is labeled as such. The playbook is marked as forthcoming because no file exists yet.

`dune-redesign.css` uses semantic Dune token names and Dune layout rules. `dune-theme.css` is a replaceable, approximate standalone light-theme mapping because the official generated Allegro token CSS is not included in this independent repository. The current flower colors are inherited framework diagram categories. Do not treat the local mapping as exact Dune token values.

The source prototype credits Frontend Platform. This adaptation retains that attribution in the footer.
